# 星火防线 · 塔防

单文件 HTML5 塔防游戏。**双击 `index.html` 即可在浏览器中游玩**，无需安装任何东西；
全部图形与音效由代码实时生成，不包含任何第三方图片 / 音频 / 字体素材。

## 玩法

- 敌人沿固定路线进攻右侧核心，漏怪扣核心生命，生命归零即失败。
- 撑过全部 **15 波**即胜利。金币来自击杀与清波奖励，「立即召唤」下一波可获得额外金币。
- 点击底部卡片选塔（或按 `1-5`），再点击草地空位建造；点击场上已建的塔可查看数值并**升级（U）**或**出售（X）**。

## 防御塔

| 塔 | 定位 | 价格 | 特点 |
|----|------|------|------|
| 箭塔 | 单体 | 60 | 高射速，性价比高 |
| 炮台 | 范围 | 110 | 炮弹落点爆炸，克制密集敌群 |
| 霜塔 | 减速 | 80 | 冰霜脉冲减速一片敌人 |
| 狙击塔 | 远程 | 150 | 超远射程高爆发，专治厚血单位 |
| 磁暴塔 | 连锁 | 130 | 闪电在敌群间跳跃，最多连锁 3 个目标，伤害逐跳衰减 |

每种塔均可升到 3 级（伤害 ×1.7/级、射程 +12/级、射速 +15%/级）。

## 敌人

步兵（均衡）、疾行者（快速）、装甲车（高血带 15% 减伤）、**分裂虫（死亡后钻出 2 只幼虫，第 7 波起登场）**、首领（第 15 波，高血带 20% 减伤）。
敌人生命随波次按 `1 + 0.20k + 0.014k²` 增长（k 为波次-1），并随难度再乘系数。

## 快捷键

`1-5` 选塔 · `U` 升级 · `X` 出售 · `N` 立即召唤下一波 · `空格/P` 暂停 ·
`F` 切换 1×/2×/3× 倍速 · `R` 重开 · `M` 静音 · `Esc`/右键 取消选择

## 难度

| 难度 | 初始生命 | 初始金币 | 敌人强度 |
|------|----------|----------|----------|
| 简单 | 20 | 250 | ×0.90，速度 ×0.95 |
| 普通 | 20 | 210 | ×1.00 |
| 困难 | 12 | 245 | ×1.19，速度 ×1.04 |
| 无尽 | 20 | 230 | ×1.05，速度 ×1.02，波次永不结束 |

## 无尽模式

- 第 16 波起由程序生成敌军：数量与密度随波次持续攀升，**逢 5 的波次有首领压阵**（第 30 波起双首领）。
- 没有胜利结算——核心陷落时的波次就是你的成绩，**最佳纪录自动保存**并显示在主菜单与结算画面。
- 参考强度：满配防线大约能守到 30 波上下，之后敌人生命增长会压过塔的输出。

## 开发与测试

`_dev/sim.js` 是无头回归测试（`node _dev/sim.js`）：在 Node 中加载游戏逻辑，
用自动建造机器人完整跑三档难度（15 波通关）+ 无尽模式（守到力竭），并执行 33 项断言（建造/升级/出售/连锁闪电/分裂虫/暂停锁定/无尽波次生成/胜负判定/UI 点击链路）。
`_dev/shot_*.png` 是 Edge 无头模式截取的开始界面 / 对局 / 胜利结算画面。
`_dev` 目录不是游戏本体的一部分，删除后不影响游戏。
