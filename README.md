# 星火防线 · 塔防

单文件 HTML5 塔防游戏。**双击 `index.html` 即可在浏览器中游玩**，无需安装任何东西；
全部图形与音效由代码实时生成，不包含任何第三方图片 / 音频 / 字体素材。

## 玩法

- 敌人沿固定路线进攻右侧核心，漏怪扣核心生命，生命归零即失败。
- 撑过全部波次即胜利。金币来自击杀与清波奖励，「立即召唤」下一波可获得额外金币。
- 点击底部卡片选塔（或按 `1-7`），再点击草地空位建造；点击场上已建的塔可查看数值并**升级（U）**或**出售（X）**。

### 窗口适配

画布铺满整个窗口，不再出现黑边：

- **宽屏**（窗口比 1000×680 更宽）：草地棋盘格与网格按同一相位向场地外延伸，顶部 HUD 与底部操作栏横贯整窗，
  画面是连续的一整片战场；越靠窗口边缘越暗，留白自然收进暗部。
- **竖屏**（窗口更方或更高）：场地等比居中，外围是带柔光的舞台底色。
- 任意窗口比例下场地都完整可见、不被裁切；点击坐标会先扣掉居中留白再换算，因此不会错位。
- 画布像素量按窗口面积限流（上限约 420 万像素），大屏下不会因为 DPR 过高而掉帧。

### 可无限升级

塔**没有等级上限**，只要金币够就能一直点「升级」（`U`）。每级收益固定叠加：

- 伤害 ×1.7/级、射程 +12/级、射速 ×1.15/级（前 5 级；之后每级 ×1.06，防止高等级射速爆炸）；
- 毒液塔的毒素伤害随等级同步提升，增幅塔每升一级光环加成 +25%（即 32% → 40% → 48% …）。

代价是**升级费按指数增长**（`cost = 塔基础价 × 0.85 × 1.7^(等级-1)`），
所以后期每多一级都极其昂贵，实际能升到几级取决于你这一局攒了多少金币——
把一座箭塔堆到 Lv.9 是可行的，但会吃掉整局大部分收入，通常不如多铺两座划算。

等级显示：1–5 级在塔下方画等级圆点；6 级起改画 `×N` 数字徽标，避免圆点铺满草地。
（内部 `MAX_LV = 99` 只是防数值溢出的安全阀，正常对局摸不到。）

> 增幅塔属于**支援型**：它占位但不输出。把它放在火力密集的塔群中间收益最高；
> 单独摆一座通常不划算。

## 敌人

步兵（均衡）、疾行者（快速）、装甲车（高血带 15% 减伤）、**分裂虫（死亡后钻出 2 只幼虫，第 7 波起登场）**、
**护盾兵（第 6 波起登场，脱战 3.5 秒后恢复护盾）**、**医疗兵（第 10 波起登场，治疗光环持续恢复周围同伴生命，不能自愈）**、
**狂怒兽（残血时最高提速 80%，越打越快）**、**蜂群（数量极多的脆弱小怪，单个只有 22 血）**、
首领（最终波，高血带 20% 减伤）。
敌人生命与护盾随波次按 `1 + 0.20k + 0.014k²` 增长（k 为波次-1），并随难度再乘系数。

## 快捷键

`1-5` 选难度/关卡 · `C` 继续游戏 · `1-7` 选塔 · `U` 升级 · `X` 出售 · `N` 立即召唤下一波 ·
`空格/P` 暂停 · `F` 切换 1×/2×/3× 倍速 · `R` 重开 · `M` 静音 · `Esc`/右键 取消选择

## 断点续战（存档）

游戏会自动把进行中的对局保存到浏览器本地（localStorage），随时可关页面后回来接着打：

- **自动存档**：对局进行中每约 4 秒写入一次；暂停、召唤下一波完成、波次清空后也会立即存盘。HUD 顶部出现绿色「已存档 ✓」即表示刚落盘。
- **继续游戏**：主菜单检测到存档时会显示「继续游戏 · <难度> · 第 N 波」按钮，点击或按 `C` 即可从存档点恢复（含防御塔、敌人、金币、生命、波次进度）。
- **存档清理**：主动选择新难度开局、对局胜利或核心陷落（失败）时，旧存档自动作废，不会出现"赢了还能续"或"输了还能刷"的幽灵存档。
- **健壮性**：存档只序列化可重建的纯数据（跳过函数、子弹引用与瞬时特效），读档时由防御塔与路径重新推导坐标；损坏、旧版本或难度字段被篡改的存档会安全降级为"无存档"，不会卡死菜单。

## 无尽模式

- 第 16 波起由程序生成敌军：数量与密度随波次持续攀升，**逢 5 的波次有首领压阵**（第 30 波起双首领）。
- 第 15 波后敌人生命获得额外递增系数（每波 +5%），曲线终会压过任何防线。
- 没有胜利结算——核心陷落时的波次就是你的成绩，**最佳纪录自动保存**并显示在主菜单与结算画面。
- 参考强度：满配防线大约能守到 27 波上下，之后敌人生命增长会压过塔的输出。

## 开发与测试

`_dev/sim.js` 是无头回归测试（`node _dev/sim.js`）：在 Node 中加载游戏逻辑，
用自动建造机器人完整跑四档难度（简单 / 普通 / 困难 15 波通关 + 熔渊 12 波通关）与无尽模式（守到力竭），
并执行 **120 项断言**，覆盖建造/升级/出售/连锁闪电/分裂虫/毒液与护盾/医疗兵治疗光环/高速弹碰撞/暂停锁定/
输入边界/无尽波次与纪录/存档读档重建/胜负判定/UI 点击链路/无限升级（连升 8 级后数值与售价正确），以及增幅塔光环、狂怒兽加速、蜂群击杀、
熔渊独立地图与炮台落点推算、视口等比适配与留白下的点击坐标还原等新增功能的回归。

`_dev/fuzz.js` 是属性化模糊测试（`node _dev/fuzz.js`）：随机状态 + 不变量校验
（金币/生命非负、坐标非 NaN、占位表与塔列表一致、阵亡单位不残留等），
用于排查难以手动复现的状态污染与崩溃。

`_dev/shot_*.png` 是 Edge 无头模式截取的开始界面 / 对局 / 熔渊关卡画面。
`_dev` 目录不是游戏本体的一部分，删除后不影响游戏。
